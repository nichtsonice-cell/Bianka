# Bianka — Come Home

Mobile-first animated picture-book website for GitHub Pages.

Put your video in the repository root as **bianka.mp4**.

Then enable GitHub Pages:
**Settings → Pages → Deploy from branch → main → /root**

The site opens like a picture book and transitions into the video. It is optimized for iPhone Safari with safe-area support, `playsinline`, muted playback after the tap, and one-tap sound.
